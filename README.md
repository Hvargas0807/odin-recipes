# Odin Recipes

## 📝 Descripción del Proyecto
Este proyecto es parte del camino fundamental de **The Odin Project**. Consiste en un sitio web básico de recetas creado desde cero, estructurado de forma limpia utilizando únicamente HTML. El objetivo principal es poner en práctica los cimientos del desarrollo web antes de avanzar hacia los estilos y diseños complejos.

## 🛠️ Habilidades Demostradas
Al finalizar este proyecto, habré demostrado un dominio sólido en:
* **Estructura de HTML:** Uso correcto de etiquetas esenciales como encabezados (`<h1>` a `<h6>`), párrafos (`<p>`), listas ordenadas (`<ol>`) y desordenadas (`<ul>`).
* **Navegación Web:** Implementación de enlaces internos y externos utilizando la etiqueta de anclaje (`<a>`).
* **Manejo de Archivos:** Organización de rutas relativas para conectar páginas internas y mostrar imágenes locales.
* **Control de Versiones:** Uso de Git y GitHub para realizar commits, gestionar repositorios y conectar mi entorno local con la nube mediante SSH.

## 💭 Reflexión Personal
*Este proyecto me ayudó a entender la importancia de mantener un código HTML semántico y bien ordenado, además de perderle el miedo a la terminal y al flujo de trabajo con Git.*
